# SQL 50

A collection of 50 SQL problems and solutions for practicing SQL queries across various difficulty levels.

## About

This repository contains 50 SQL problems designed to help you improve your SQL skills. The problems cover fundamental to advanced SQL concepts including:

- SELECT queries
- JOINs
- Aggregation functions
- Subqueries
- Window functions
- Data manipulation
- Complex filtering and grouping

## Structure

Each problem includes:
- Problem description
- Sample input/output
- SQL solution

## Getting Started

1. Clone the repository
2. Navigate to a problem directory
3. Read the problem description
4. Write your SQL solution
5. Compare with the provided solution

## Topics Covered

- Basic SELECT statements
- WHERE clauses and filtering
- JOINs (INNER, LEFT, RIGHT, FULL)
- GROUP BY and HAVING
- Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
- Subqueries and CTEs
- Window functions (ROW_NUMBER, RANK, DENSE_RANK)
- String and date functions
- Data insertion and updates

## Prerequisites

- Basic understanding of SQL
- SQL database (MySQL, PostgreSQL, SQLite, or similar)
- Text editor or IDE
